JBolt 平台公共后台模板，与 cn.jbolt._admin 及部分 cn.jbolt.admin 模块对应。
common：后台布局、弹窗、表单与公共组件；index：登录、首页、锁屏与看板。
user、role、permission、rolepermission、dept、post：用户与组织权限管理。
dictionary、globalconfig、userconfig：字典、全局配置与用户配置。
systemlog、loginlog、onlineuser、servermonitor：日志、在线用户与服务器监控。
msgcenter：私信、系统通知与待办；topnav：顶部导航。
qiniu、hiprint、sensitiveword：存储、打印模板与敏感词管理。
_app_dev_center、_dev_doc、_jbolt_code_gen：应用管理、数据库文档与代码生成器。
_wechat：微信后台管理；customtablerender：自定义表格渲染示例。
Siargo 业务模板位于 _view/admin/siargo，复用本目录的公共布局和组件。
