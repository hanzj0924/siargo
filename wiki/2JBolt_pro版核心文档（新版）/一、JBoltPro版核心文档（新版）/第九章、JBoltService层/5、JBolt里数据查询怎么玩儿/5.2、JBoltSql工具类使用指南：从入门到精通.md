## 简介

JBolt框架中的`Sql`类是一个强大的SQL构建工具，它提供了一种面向对象的方式来构建和执行SQL语句。通过链式调用方法，可以轻松构建复杂的SQL查询，而无需手动拼接SQL字符串。这不仅提高了代码的可读性和可维护性，还减少了SQL注入的风险。

`Sql`类支持多种数据库类型，包括MySQL、PostgreSQL、Oracle、SQL Server和达梦等，能够自动处理不同数据库之间的语法差异。

## 基础知识

### 创建Sql对象

创建`Sql`对象有多种方式，根据不同的数据库类型：

```java
// 创建MySQL类型的Sql对象
Sql sql = Sql.mysql();

// 创建PostgreSQL类型的Sql对象
Sql sql = Sql.postgresql();

// 创建Oracle类型的Sql对象
Sql sql = Sql.oracle();

// 创建SQL Server类型的Sql对象
Sql sql = Sql.sqlserver();

// 创建达梦类型的Sql对象
Sql sql = Sql.dm();

// 或者使用通用方法，指定数据库类型
Sql sql = Sql.me(DBType.MYSQL);
```

### 数据库类型

JBolt支持多种数据库类型，在`DBType`类中定义：

- `DBType.MYSQL`: MySQL数据库
- `DBType.POSTGRESQL`: PostgreSQL数据库
- `DBType.ORACLE`: Oracle数据库
- `DBType.SQLSERVER`: SQL Server数据库
- `DBType.DM`: 达梦数据库
- `DBType.H2`: H2数据库
- `DBType.SQLITE`: SQLite数据库
- `DBType.DB2`: DB2数据库

### 基本SQL操作

`Sql`类支持基本的SQL操作，包括SELECT、INSERT、UPDATE和DELETE。

## 查询操作

### 基本查询

```java
// 基本查询
Sql sql = Sql.mysql()
    .select("id, name, age")
    .from("user");
    
// 查询所有字段
Sql sql = Sql.mysql()
    .select()  // 或 .select("*")
    .from("user");
    
// 使用Model类指定表名
Sql sql = Sql.mysql()
    .select()
    .from(User.class);
    
// 使用表别名
Sql sql = Sql.mysql()
    .select("u.id, u.name, u.age")
    .from("user", "u");
```

### 条件查询

```java

Sql sql = Sql.mysql()

    .from("user")

// 不等于条件
Sql sql = Sql.mysql()

    .from("user")

// 大于条件
Sql sql = Sql.mysql()

    .from("user")
    .gt("age", 18);  // WHERE age > 18
    
// 小于条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .lt("age", 60);  // WHERE age < 60
    
// 大于等于条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .ge("age", 18);  // WHERE age >= 18
    
// 小于等于条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .le("age", 60);  // WHERE age <= 60
    
// LIKE条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .like("name", "张");  // WHERE name LIKE '%张%'
    
// 左LIKE条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .leftLike("name", "张");  // WHERE name LIKE '张%'
    
// 右LIKE条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .rightLike("name", "张");  // WHERE name LIKE '%张'
    
// IN条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .in("id", 1, 2, 3);  // WHERE id IN (1, 2, 3)
    
// NOT IN条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .notIn("id", 1, 2, 3);  // WHERE id NOT IN (1, 2, 3)
    
// BETWEEN条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .between("age", 18, 60);  // WHERE age BETWEEN 18 AND 60
    
// IS NULL条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .isNull("email");  // WHERE email IS NULL
    
// IS NOT NULL条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .isNotNull("email");  // WHERE email IS NOT NULL
```

### 复合条件

```java
// AND条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .eq("status", 1)
    .and()
    .gt("age", 18);  // WHERE status = 1 AND age > 18
    
// OR条件
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .eq("status", 1)
    .or()
    .eq("status", 2);  // WHERE status = 1 OR status = 2
    
// 括号分组
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .bracketLeft()
    .eq("status", 1)
    .or()
    .eq("status", 2)
    .bracketRight()
    .and()
    .gt("age", 18);  // WHERE (status = 1 OR status = 2) AND age > 18
```

### 排序和分组

```java
// 单字段排序
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .orderBy("age", true);  // ORDER BY age DESC
    
// 多字段排序
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .orderBy("age", false)  // 升序
    .orderBy("create_time", true);  // 降序
    
// 使用asc和desc方法
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .asc("age")  // ORDER BY age ASC
    .desc("create_time");  // ORDER BY age ASC, create_time DESC
    
// 分组查询
Sql sql = Sql.mysql()
    .select("dept_id, COUNT(*) as count")
    .from("user")
    .groupBy("dept_id");  // GROUP BY dept_id
    
// 分组后过滤
Sql sql = Sql.mysql()
    .select("dept_id, COUNT(*) as count")
    .from("user")
    .groupBy("dept_id")
    .having("COUNT(*) > 5");  // GROUP BY dept_id HAVING COUNT(*) > 5
```

### 连接查询

```java
// 左连接

    .select("u.id, u.name, d.name as dept_name")

    .select("u.id, u.name, d.name as dept_name")

    .select("u.id, u.name, d.name as dept_name")

    .select("u.id, u.name, d.name as dept_name")
    .from(User.class, "u")
    .leftJoin(Department.class, "d", "u.dept_id = d.id");

Sql sql = Sql.mysql()
    .select("u.id, u.name, d.name as dept_name")
    .from("user", "u")
    .leftJoin("department", "d", "u.dept_id", "d.id");
    
// 基于ID的连接

    .select("u.id, u.name, d.name as dept_name")
    .from("user", "u")
    .leftJoinOnId("department", "d", "u.dept_id");
```

## 更新操作

```java
// 基本更新
Sql sql = Sql.mysql()
    .update("user")
    .set("name", "张三")
    .set("age", 25)
    .eq("id", 1);
    
// 条件更新
Sql sql = Sql.mysql()
    .update("user")
    .set("status", 0)
    .eq("dept_id", 5)
    .and()
    .lt("create_time", new Date());
    
// 使用SQL表达式更新
Sql sql = Sql.mysql()
    .update("user")
    .set("login_count", "login_count + 1")
    .eq("id", 1);
    
// 使用setSqlExpress方法
Sql sql = Sql.mysql()
    .update("user")
    .setSqlExpress("login_count", "login_count + 1")
    .eq("id", 1);
    
// 递增字段值
Sql sql = Sql.mysql()
    .update("user")
    .plus("login_count")  // login_count = login_count + 1
    .eq("id", 1);
    
// 递增指定值
Sql sql = Sql.mysql()
    .update("user")
    .plus("score", 5)  // score = score + 5
    .eq("id", 1);
    
// 递减字段值
Sql sql = Sql.mysql()
    .update("user")
    .minus("remaining_attempts")  // remaining_attempts = remaining_attempts - 1
    .eq("id", 1);
    
// 递减指定值
Sql sql = Sql.mysql()
    .update("user")
    .minus("score", 3)  // score = score - 3
    .eq("id", 1);
```

## 高级功能

### Union查询

```java
// UNION查询
Sql sql1 = Sql.mysql()
    .select("id, name, 'employee' as type")
    .from("employee");
    
Sql sql2 = Sql.mysql()
    .select("id, name, 'customer' as type")
    .from("customer");
    
sql1.union(sql2);  // 使用UNION

// UNION ALL查询
sql1.unionAll(sql2);  // 使用UNION ALL
```

### 子查询

```java
// IN子查询
Sql subSql = Sql.mysql()
    .select("dept_id")
    .from("department")
    .eq("status", 1);
    
Sql sql = Sql.mysql()
    .select()
    .from("user")
    .inSql("dept_id", subSql);  // WHERE dept_id IN (SELECT dept_id FROM department WHERE status = 1)
    
// EXISTS子查询
Sql subSql = Sql.mysql()
    .select("1")
    .from("order")
    .eqInnerColumn("user_id", "u.id");
    
Sql sql = Sql.mysql()
    .select()
    .from("user", "u")
    .exists(subSql);  // WHERE EXISTS (SELECT 1 FROM order WHERE user_id = u.id)
```

### 复杂条件构建

```java
// 复杂条件示例
Sql sql = Sql.mysql()
    .select("u.id, u.name, d.name as dept_name, COUNT(o.id) as order_count")
    .from("user", "u")
    .leftJoin("department", "d", "u.dept_id = d.id")
    .leftJoin("order", "o", "o.user_id = u.id")
    .bracketLeft()
    .eq("u.status", 1)
    .or()
    .bracketLeft()
    .eq("u.status", 0)
    .and()
    .gt("u.create_time", DateUtil.addDays(new Date(), -7))
    .bracketRight()
    .bracketRight()
    .and()
    .eq("d.status", 1)
    .groupBy("u.id, u.name, d.name")
    .having("COUNT(o.id) > 0")
    .orderBy("order_count", true)
    .page(1, 20);

/* 生成的SQL:
SELECT u.id, u.name, d.name as dept_name, COUNT(o.id) as order_count
FROM user u
LEFT JOIN department d ON u.dept_id = d.id
LEFT JOIN order o ON o.user_id = u.id
WHERE (u.status = 1 OR (u.status = 0 AND u.create_time > ?) ) AND d.status = 1
GROUP BY u.id, u.name, d.name
HAVING COUNT(o.id) > 0
ORDER BY order_count DESC
LIMIT 20 OFFSET 0
*/
```

## 在Service层中使用

JBolt框架提供了三种基础Service类，它们都内置了对Sql工具类的支持：

- `JBoltBaseService`: 用于操作Model对象
- `JBoltBaseRecordService`: 用于操作Record对象
- `JBoltApiBaseService`: 用于API接口服务

### JBoltBaseService中的使用

`JBoltBaseService`是基于JFinal的Model进行操作的基础服务类。

```java
public class UserService extends JBoltBaseService<User> {
    
    @Override
    protected User dao() {
        return User.dao;
    }
    
    // 使用Sql查询用户列表
    public List<User> findActiveUsers() {
        // 创建查询SQL
        Sql sql = selectSql()  // 使用内置的selectSql()方法
            .eq("status", 1)
            .orderBy("create_time", true);
        
        // 执行查询
        return find(sql);
    }

     // 使用Sql查询用户列表 链式简写形式
    public List<User> findActiveUsers() {
        // 创建查询SQL并执行find(sql)
        return find(selectSql()
            .eq("status", 1)
            .orderBy("create_time", true));
    }
    
    // 分页查询
    public Page<User> paginateUsers(int pageNumber, int pageSize, String keyword) {
        Sql sql = selectSql()
            .like("name", keyword)
            .eq("status", 1)
            .orderBy("create_time", true)
            .page(pageNumber, pageSize);
        
        return paginate(sql);
    }

     // 分页查询 简写形式
    public Page<User> paginateUsers(int pageNumber, int pageSize, String keyword) {
        return paginate(selectSql()
            .like("name", keyword)
            .eq("status", 1)
            .orderBy("create_time", true)
            .page(pageNumber, pageSize)
            );
    }
    
    // 更新用户状态
    public boolean updateUserStatus(Long userId, int status) {
        Sql sql = updateSql()  // 使用内置的updateSql()方法
            .set("status", status)
            .eq("id", userId);
        
        return update(sql) > 0;
    }
    
    // 删除用户 这里只是为了演示sql 内置我们已经有deleteById方法了
    public boolean deleteUser(Long userId) {
 
        return delete(
            deleteSql()  // 使用内置的deleteSql()方法
            .eq("id", userId)) > 0;
    }
    
    // 复杂查询示例
    public List<User> findUsersByDepartment(Long deptId, Date startDate, Date endDate) {
        Sql sql = selectSql()
            .select("u.*")
            .from(User.class, "u")
            .leftJoin("user_department", "ud", "u.id = ud.user_id")
            .eq("ud.department_id", deptId)
            .and()
            .between("u.create_time", startDate, endDate)
            .orderBy("u.create_time", false);
        
        return find(sql);
    }
}
```

### JBoltBaseRecordService中的使用

`JBoltBaseRecordService`是基于JFinal的Record进行操作的基础服务类。

```java
public class ProductService extends JBoltBaseRecordService {
    
    @Override
    protected String getTableName() {
        return "product";
    }
    
    @Override
    protected String getDataSourceConfigName() {
        return "main";
    }
    
    @Override
    protected String getPrimaryKey() {
        return "id";
    }
    
    @Override
    protected String getIdGenMode() {
        return JBoltIDGenMode.SNOWFLAKE;
    }
    
    // 使用Sql查询产品列表
    public List<Record> findActiveProducts() {
        Sql sql = selectSql()
            .eq("status", 1)
            .orderBy("create_time", true);
        
        return find(sql);
    }
    
    // 分页查询
    public Page<Record> paginateProducts(int pageNumber, int pageSize, String keyword) {
        Sql sql = selectSql();
        
        if (StrKit.notBlank(keyword)) {
            sql.like("name", keyword);
        }
        
        sql.eq("status", 1)
           .orderBy("create_time", true)
           .page(pageNumber, pageSize);
        
        return paginate(sql, true);  // 第二个参数表示是否将结果的列名转为驼峰命名
    }
    
    // 复杂查询示例
    public List<Record> findProductsByCategoryWithSales(Long categoryId) {
        Sql sql = selectSql()
            .select("p.*, COUNT(o.id) as order_count, SUM(o.quantity) as total_sales")
            .from("product", "p")
            .leftJoin("order_item", "o", "p.id = o.product_id")
            .eq("p.category_id", categoryId)
            .and()
            .eq("p.status", 1)
            .groupBy("p.id")
            .orderBy("total_sales", true);
        
        return find(sql, true);  // 转为驼峰命名
    }
}
```

### JBoltApiBaseService中的使用

`JBoltApiBaseService`是专为API接口设计的基础服务类。

```java
public class ApiUserService extends JBoltApiBaseService {
    
    private final UserService userService = enhance(UserService.class);
    
    // API接口：获取用户列表
    public Ret getUserList(int pageNumber, int pageSize, String keyword) {
        try {
            Sql sql = Sql.mysql()
                .select()
                .from("user")
                .eq("status", 1);
                
            if (StrKit.notBlank(keyword)) {
                sql.like("name", keyword);
            }
            
            sql.orderBy("create_time", true)
               .page(pageNumber, pageSize);
            
            Page<Record> page = Db.paginate(pageNumber, pageSize, 
                sql.getSelect(), 
                sql.toSqlExceptSelect(), 
                sql.getWhereValues());
            
            return success("data", page);
        } catch (Exception e) {
            LOG.error("获取用户列表失败", e);
            return fail("获取用户列表失败");
        }
    }
    
    // 使用已有Service的方法
    public Ret getUserInfo(Long userId) {
        try {
            User user = userService.findById(userId);
            if (user == null) {
                return fail("用户不存在");
            }
            return success("data", user);
        } catch (Exception e) {
            LOG.error("获取用户信息失败", e);
            return fail("获取用户信息失败");
        }
    }
}
```

## 最佳实践

1. **使用链式调用**：充分利用Sql类的链式调用特性，使代码更加简洁明了。

2. **使用prepared语句**：对于需要防止SQL注入的场景，使用`prepared()`方法启用预处理语句。

   ```java
   Sql sql = Sql.mysql()
       .prepared()
       .select()
       .from("user")
       .eq("name", userInput);
   ```

3. **合理使用表别名**：在复杂查询中使用表别名，提高SQL的可读性。

   ```java
   Sql sql = Sql.mysql()
       .select("u.id, u.name, d.name as dept_name")
       .from("user", "u")
       .leftJoin("department", "d", "u.dept_id = d.id");
   ```

4. **使用Service层封装**：在Service层封装Sql操作，避免在Controller层直接使用Sql类。

5. **利用内置方法**：使用JBoltBaseService和JBoltBaseRecordService中的内置方法，如`selectSql()`、`updateSql()`等，简化代码。

6. **处理空值**：使用`ignoreIfValueIsNull`参数来处理可能为空的条件值。

   ```java
   Sql sql = Sql.mysql()
       .select()
       .from("user")
       .eq("dept_id", deptId, true);  // 当deptId为null时，忽略此条件
   ```

7. **使用适当的数据库类型**：根据实际使用的数据库，选择正确的数据库类型创建Sql对象。

## 常见问题解答

**Q: 如何处理不同数据库之间的SQL差异？**

A: Sql类会根据指定的数据库类型自动处理SQL语法差异，只需在创建Sql对象时指定正确的数据库类型即可。

**Q: 如何在查询中使用复杂的子查询？**

A: 可以先创建子查询的Sql对象，然后使用`inSql()`、`exists()`等方法将子查询添加到主查询中。

**Q: 如何处理大量的动态查询条件？**

A: 可以根据条件是否存在，动态添加查询条件，使用`ignoreIfValueIsNull`或`ignoreIfValueIsBlank`参数可以简化这一过程。

**Q: 如何在Service层中复用Sql查询？**

A: 可以创建通用的方法来构建基础查询，然后在不同的业务方法中扩展这些查询。

**Q: 如何处理分页查询的总记录数？**

A: 使用`JBoltBaseService`的`paginate()`方法可以自动处理分页查询的总记录数计算。

**Q: 如何在多表连接查询中避免字段名冲突？**

A: 使用表别名和字段别名来避免冲突，例如`select("u.id as user_id, d.id as dept_id")`。
