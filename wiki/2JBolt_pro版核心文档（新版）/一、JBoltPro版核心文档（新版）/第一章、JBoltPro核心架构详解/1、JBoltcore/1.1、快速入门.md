## 1. 框架简介

### 1.1 什么是JBolt Core

JBolt Core是基于JFinal框架的企业级Java Web开发框架核心库，提供了完整的MVC架构支持、丰富的业务组件和开箱即用的功能模块。

### 1.2 技术栈

- **基础框架**: JFinal 5.2.4
- **模板引擎**: Enjoy
- **数据库**: 支持MySQL、Oracle、PostgreSQL、SQL Server、达梦等
- **缓存**: EhCache、Caffeine、Redis
- **其他**: JWT、POI、FastJSON等

### 1.3 框架特点

- 🚀 **高性能**: 基于JFinal的高性能架构
- 📦 **模块化**: 功能模块化设计，按需使用
- 🔧 **易扩展**: 提供丰富的扩展点
- 🛡️ **安全性**: 内置XSS防护、权限控制等安全机制
- 🌍 **多数据库**: 支持主流数据库，自动适配方言

## 3. 核心概念

### 3.1 分层架构

JBolt Core采用经典的三层架构：

1. **Controller层**: 处理HTTP请求，调用Service
2. **Service层**: 业务逻辑处理，事务管理
3. **Model层**: 数据模型，数据库操作

### 3.2 约定优于配置

- 表名与Model类名对应（支持驼峰转下划线）
- 主键默认为`id`
- 布尔字段使用`enable`、`is_deleted`等
- 排序字段使用`sort_rank`

### 3.3 链式SQL构建

```java
// 链式构建SQL
List<User> users = find(
    selectSql()
        .select("id", "name", "email")
        .eq("enable", true)
        .like("name", keyword)
        .orderByIdDesc()
        .page(1, 20)
);
```

```java
public class UserController extends JBoltBaseController {
```

### 4.2 Service开发

```java
public class UserService extends JBoltBaseService<User> {
    
    private User dao = new User().dao();
    
    @Override
    protected User dao() {
        return dao;
    }
    
    /**
     * 分页查询
     */
    public Page<User> paginateAdminList(int pageNumber, int pageSize, String keywords) {
        return paginateByKeywords(
            "id", "desc", 
            pageNumber, pageSize, 
            keywords, 
            "name,username,email"
        );
    }
    
    /**
     * 保存用户
     */
    public Ret save(User user) {
        // 验证
        if (existsName(user.getName())) {
            return fail("用户名已存在");
        }
        
        // 设置默认值
        user.setEnable(true);
        user.setCreateTime(new Date());
        
        // 保存
        boolean success = user.save();
        return ret(success);
    }
    
    /**
     * 更新用户
     */
    public Ret update(User user) {
        // 验证
        if (existsName(user.getName(), user.getId())) {
            return fail("用户名已存在");
        }
        
        // 更新
        user.setUpdateTime(new Date());
        boolean success = user.update();
        return ret(success);
    }
    
    /**
     * 检查是否可以删除
     */
    @Override
    public String checkCanDelete(User user, Kv kv) {
        // 检查是否有关联数据
        if (existsUserOrder(user.getId())) {
            return "该用户存在订单，不能删除";
        }
        return null;
    }
}
```

```java
public class MyConfig extends JFinalConfig {

        // 主数据源

        me.add(mainDp);
```

## 6. 高级应用

### 6.1 复杂SQL构建

```java
// 复杂查询示例
public Page<Record> complexQuery(Kv params) {
    Sql sql = selectSql()
        .select("u.*, d.name as dept_name, r.name as role_names")
        .from(User.class, "u")
        .leftJoin(Dept.class, "d", "u.dept_id=d.id")
        .leftJoin("user_role ur", "ur", "u.id=ur.user_id")
        .leftJoin(Role.class, "r", "ur.role_id=r.id")
        .eq("u.enable", true)
        .likeMulti(params.getStr("keywords"), "u.name", "u.username")
        .between("u.create_time", params.getDate("startDate"), params.getDate("endDate"))
        .groupBy("u.id")
        .having("count(r.id) > 0")
        .orderBy("u.create_time", "desc")
        .page(params.getInt("pageNumber"), params.getInt("pageSize"));
    
    return paginateRecord(sql);
}
```

### 6.2 事务管理

```java
// 声明式事务
@Before(Tx.class)
public Ret complexSave(User user, List<Long> roleIds) {
    // 保存用户
    user.save();
    
    // 保存用户角色关系
    for (Long roleId : roleIds) {
        UserRole ur = new UserRole();
        ur.setUserId(user.getId());
        ur.setRoleId(roleId);
        ur.save();
    }
    
    return SUCCESS;
}

// 编程式事务
public Ret batchUpdate(List<User> users) {
    return Db.tx(() -> {
        for (User user : users) {
            user.update();
        }
        return true;
    }) ? SUCCESS : FAIL;
}
```

```java
@ServerEndpoint("/websocket/{userId}")
public class MyWebSocket {
    
    @OnOpen
    public void onOpen(Session session, @PathParam("userId") Long userId) {
        WebSocketManager.addSession(userId, session);
    }
    
    @OnMessage
    public void onMessage(String message, Session session) {
        // 处理消息
        JSONObject json = JSON.parseObject(message);
        String type = json.getString("type");
        
        if ("broadcast".equals(type)) {
            WebSocketManager.broadcast(json.getString("content"));
        }
    }
    
    @OnClose

        WebSocketManager.removeSession(session);
    }
}
```

## 8. 性能优化

### 8.1 数据库优化

1. **索引优化**
   ```sql
   -- 为常用查询字段建立索引
   CREATE INDEX idx_user_username ON user(username);
   CREATE INDEX idx_user_create_time ON user(create_time);
   ```

2. **查询优化**
   ```java
   // 只查询需要的字段
   List<User> users = find(
       selectSql().select("id", "name", "username")
   );
   
   // 避免N+1查询
   List<Record> records = Db.find(
       "select u.*, d.name as dept_name " +
       "from user u " +
       "left join dept d on u.dept_id = d.id"
   );
   ```

### 8.2 缓存策略

1. **多级缓存**
   ```java
   // 一级缓存：进程内缓存
   @JBoltAutoCache(name = "caffeine")
   
   // 二级缓存：Redis缓存
   @JBoltAutoCache(name = "redis")
   ```

2. **缓存更新策略**
   ```java
   // 更新时清除缓存
   public Ret update(User user) {
       boolean success = user.update();
       if (success) {
           deleteCacheById(user.getId());

       return ret(success);
   }
   ```

### 8.3 代码优化

1. **延迟加载**
   ```java

               if (userService == null) {
                   userService = Aop.get(UserService.class);

           }
       }

   }
   ```

2. **异步处理**
