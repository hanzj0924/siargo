# Siargo 开发与业务手册

> 核对日期：2026-09-30；源码基线：v2.9.4 / Git `18c1de8`。适用项目为 `D:/Workspace/siargo`，不适用于独立的 `siargo_ai`。

这套手册按当前业务代码、页面、配置及实际依赖重新编写。内容覆盖开发维护和业务链理解，所有阅读入口均位于本目录或指向当前项目源码；旧资料目录由用户另行处理，删除旧目录不会影响本手册。

## 从哪里开始

- 了解系统：先读[核心架构](01-JBolt平台核心架构.md)、[业务模块地图](07-业务模块地图.md)，再进入对应业务专题。
- 修改功能：先读业务专题的操作、状态、数据和失败边界，再读所涉及的分层指南。
- 配置或发布：读[配置速查](08-项目配置速查手册.md)及项目正式发布流程；文档本身不要求执行启动、迁移或打包。
- 查平台能力：读[JBolt 原生机制](jbolt-native-mechanisms.md)，区分项目已使用的功能、框架可选能力和参考示例。

## 如何理解证据与限制

| 标记或表述 | 含义 |
| --- | --- |
| 当前实现 / 源码已核实 | 已沿当前源码、模板或依赖实现检查，未据此宣称运行验收通过 |
| 开发规范 | 后续修改应遵循的要求，不表示全部历史分支已经完全满足 |
| 平台能力 / 可选能力 | 框架或平台模块存在相关接口，还需配置、注册、权限和业务接入 |
| 当前限制 / 未核实 | 保留真实差异，不用理想流程补写成既有功能 |

数据库方面，本次只读核实本机 `siargo` 的 `information_schema.COLUMNS`：业务前缀下为 23 张表、202 个字段。该结果仅代表本次本机元数据快照，不代表线上结构，也不代表完整索引、外键及数据一致性均已验证。未读取业务记录、未写库、未运行服务或浏览器验收。

源码路径与类/方法是定位依据。存在代码注释漂移时，以实际执行分支和 SQL 为准；生成模型注释、历史 SQL、旧文档和另一个项目的实现均不能替代当前事实。

## 维护约定

业务事实只在所属专题维护：审批状态归 11、目录变更归 10、导入输出协议归 12、报告统计归 15；其他篇章用简短关系说明和链接引用。公共事务、序列化、资源及配置机制分别由 03、04、05、08 维护。

更新文档时同步核对页面入口、Controller、Service、模型/数据库、前端消费者和文件操作。只调整本次需求涉及的事实，不因文档发现问题顺带修改业务代码；实现缺口在相应章节说明。配置示例不保留真实密码、密钥或签名。

项目规则以 [AGENTS.md](../../AGENTS.md) 为入口；正式发布按 [siargo-package.md](../../siargo-package.md) 执行。新增接口仍须遵守应用中心统一管理要求，不能将应用资料管理等同于完整接口治理。
