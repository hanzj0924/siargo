### 3.4 equipment（设备管理）

- **类型**：主子表 + 多级审批流程 + 时间线
- **数据表**：
  - `siargo_equipment`（17字段：基本信息 + 检验周期 + 位置/负责人 + 状态）
  - `siargo_equipment_comparison`（11字段：设备ID + 对比信息 + 编制人/审核人 + 审核状态）
  - `siargo_equipment_repair`（10字段：设备ID + 故障描述 + 维修措施 + 维修结果）
  - `siargo_equipment_certificate`（7字段：设备ID + 证书图片路径 + 日期）
- **源码文件**：
  ```
  admin/siargo/equipment/EquipmentAdminController.java (256行)
  admin/siargo/equipment/EquipmentService.java
  admin/siargo/equipment/certificate/EquipmentCertificateService.java
  admin/siargo/equipment/comparison/EquipmentComparisonService.java
  admin/siargo/equipment/repair/EquipmentRepairService.java
  siargo/model/Equipment.java / EquipmentComparison.java / EquipmentRepair.java / EquipmentCertificate.java
  ```
- **页面文件**：
  ```
  _view/admin/siargo/equipment/
  ├── index.html              # 设备列表（多条件搜索 + 批量操作）
  ├── add.html / edit.html    # 新增/编辑
  ├── _form.html              # 表单模板
  ├── batchInspection.html    # 批量检验
  ├── batchStatus.html        # 批量状态变更
  ├── certificates.html       # 证书查看
  ├── inspectionBatch/        # 对比记录子模块
  ├── repair/                 # 维修记录子模块
  └── timeline/               # 时间线
  ```
- **核心功能**：
  - 设备 CRUD + 多条件筛选（category/filter/status/inspectionMethod/inspectionCycle）
  - 批量编制检验单（编制→审核两阶段流程）
  - 设备对比记录管理（审核状态 tracking）
  - 设备维修记录
  - 设备证书图片上传
  - 设备时间线（对比+维修记录合并）
  - 批量状态变更
  - 概览统计（缓存）
- **URL 路由**：`/admin/siargo/equipment`
- **审批流程**：编制 → 审核（creator_id/auditor_id + audit_status）
- **学习要点**：审批流程、主子表管理、多条件搜索、批量操作、时间线

### 3.5 qarep（检验报告单）

- **类型**：最复杂模块，多阶段全生命周期
- **数据表**：
  - `siargo_qareport`（6字段：报告单基本信息）
  - `siargo_product`（32字段：产品明细 + 审批状态 + 电参数 + 软删除）
- **源码文件**：
  ```
  admin/siargo/qarep/QareportAdminController.java (643行)
  admin/siargo/qarep/QareportService.java (992行)
  admin/siargo/qarep/ProductService.java
  admin/siargo/qarep/PDFService.java
  admin/siargo/qarep/ExcelService.java
  siargo/model/Qareport.java / Product.java
  ```
- **页面文件**：
  ```
  _view/admin/siargo/qarep/
  ├── index.html          # 多Tab流程管理（1350行）
  ├── add.html            # 新增报告单
  ├── edit.html           # 编辑
  ├── editdes.html        # 编辑产品描述
  ├── details.html        # 报告单详情
  └── inactiveList.html   # 回收站
  ```
- **核心功能**：
  - **多阶段审批流程**：编制 → 精度检验(insp=2) → 外观检验(insp=3) → 包装检验(insp=4) → 批准(insp=5)
  - **多 Tab 表格**：按 insp 状态分标签展示，每阶段独立检验
  - **Excel 导入**：上传 Excel 文件自动解析报告单数据
  - **PDF 生成**：批量生成 PDF（月度归档 + 选中生成）
  - **待办通知**：审批完成后通知下一阶段角色
  - **回收站**：软删除（vd 字段模式）→ 恢复 → 永久删除
  - **流程统计缓存**：Caffeine TTL 10分钟
  - **多 Service 协作**：QareportService + ProductService + PDFService + ExcelService + CustomerService + RoleService
- **审批流程与角色对应**：

  ```
  insp=1（待检）→ 编制人员录入
      ├── insp=2（精度检验）→ 角色SN 211 精度检验员
      ├── insp=3（外观检验）→ 角色SN 212 外观检验员
      ├── insp=4（包装检验）→ 角色SN 213 包装检验员
      └── insp=5（最终放行）→ 角色SN 214 批准员
  ```

- **URL 路由**：`/admin/siargo/qarep`
- **学习要点**：多阶段流程、缓存模式、PDF生成、Excel导入、回收站、批量审批、待办通知

### 3.6 api（对外API接口）

- **类型**：开放 API + Token 验证
- **数据表**：无专属表（使用 `siargo_api_call_log` 记录调用日志）
- **源码文件**：
  ```
  admin/siargo/api/OrderStatusApiController.java (136行)
  admin/siargo/api/SiargoApiTokenUtil.java
  ```
- **核心功能**：
  - 订单状态查询：`GET /api/siargo/order/status?orderId=xxx&token=xxx`
  - 批量订单查询：`GET /api/siargo/order/batchStatus?orderIds=xxx,yyy&token=xxx`
  - Token 验证：MD5 签名校验
  - 完整 API 调用日志记录（IP/耗时/响应码/User-Agent）
- **URL 路由**：`/api/siargo/order`（无登录认证）
- **学习要点**：API 接口开发、Token 验证、调用日志

## 六、新增模块开发步骤

1. 设计数据库表（遵循 `06-数据库设计规范`）
2. 执行 CREATE TABLE
3. 运行代码生成器 → 生成 BaseModel
4. 创建业务 Model（继承 BaseModel + @TableBind）
5. 创建 Service（继承 JBoltBaseService<M>）
6. 创建 Controller（继承 JBoltBaseController + @Path 注解）
7. 创建前端页面（_view 目录下 index/add/edit/_form.html）
8. 在 ProjectConfig 中无需额外配置（已扫描 `cn.jbolt.admin.siargo` 包）
