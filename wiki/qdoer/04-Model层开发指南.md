# Model 层开发指南

> 本文档涵盖 JBolt Model 层的双文件架构、数据库表结构、字段规范和代码生成流程。

---

## 一、Model 层定位

Model 层是数据访问的基础，在 JFinal ActiveRecord 中每个 Model 对应数据库中的一张表。

siargo 项目使用**双文件架构**：
- `base/BaseXxxModel.java` → 代码生成器自动生成，**不可手动修改**
- `XxxModel.java` → 业务扩展类，继承 BaseModel

## 四、JBoltBaseModel 核心 API

### 4.1 数据操作

```java
// 获取 DAO 实例
Customer dao = new Customer().dao();

// 保存
Customer customer = new Customer();
customer.setName("新客户");
boolean success = customer.save();

// 更新
customer.setName("修改后的名称");
customer.update();

// 删除
customer.delete();
```

### 4.2 类型获取方法

```java
// 注意：使用 set/get 方法，不是传统 JavaBean 的 getter/setter
Long id = model.getLong("id");
String name = model.getStr("name");
Integer count = model.getInt("count");
Date time = model.getDate("create_time");
Boolean flag = model.getBoolean("is_active");
Double value = model.getDouble("price");
BigDecimal amount = model.getBigDecimal("amount");
```

### 4.3 查询方法

```java
// 按主键查询
Customer customer = new Customer().dao().findById(123456789L);

// 条件查询
List<Customer> list = new Customer().dao()
    .find("SELECT * FROM siargo_customer WHERE name LIKE ?", "%关键词%");

// 查第一条
Customer first = new Customer().dao()
    .findFirst("SELECT * FROM siargo_customer WHERE id = ?", id);

// 分页
Page<Customer> page = new Customer().dao()
    .paginate(1, 10, "SELECT *", "FROM siargo_customer ORDER BY id DESC");
```

### 4.4 链式调用

```java
// Setter 返回自身，支持链式调用
Customer customer = new Customer()
    .setName("客户名称")
    .setId(123L);
customer.save();
```

## 五、主键策略：雪花算法（Snowflake）

### 5.1 为什么使用雪花算法

- **分布式友好**：各节点独立生成 ID，无需数据库自增锁
- **趋势递增**：利于数据库索引性能
- **全局唯一**：64位长整型，包含时间戳+机器ID+序列号

### 5.2 配置方式

```properties
# config.properties
global_default_id_gen_mode = snowflake
```

```java
// Model 注解中指定
@TableBind(..., idGenMode = JBoltIDGenMode.SNOWFLAKE)
```

### 5.3 ID 序列化

雪花 ID 是 Long 类型（值较大，如 `1234567890123456789`），JSON 序列化时使用 `@JSONField(serializeUsing = ToStringSerializer.class)` 转为字符串，避免前端精度丢失。

## 八、表字段规范总结

### 8.1 命名规范

- 表名前缀：`siargo_`（业务表）/ `jb_`（系统表）
- 全部 snake_case（小写+下划线）
- 关联外键：`关联表名_id`（如 `equipment_id`、`report_id`）

### 8.2 字段类型规范

| 场景 | 类型 | 说明 |
|------|------|------|
| 主键 | `bigint` | 雪花算法生成 |
| 字符串 | `varchar(N)` | N根据实际需求 |
| 长文本 | `text` / `varchar(1000)` | 备注/描述 |
| 状态/标志 | `tinyint` | 注释中标注枚举值含义 |
| 日期 | `date` | YYYY-MM-DD |
| 时间 | `datetime` | YYYY-MM-DD HH:MM:SS（非 timestamp） |
| 小数 | `double(M,D)` | 如 `double(5,3)` |
| 整数 | `int` | 数量、排序等 |
| MD5哈希 | `char(32)` | 固定长度 |

### 8.3 软删除模式

siargo 项目使用两种软删除模式：

**模式1（DMS/Image/Equipment）**：
```sql
status tinyint DEFAULT 1  -- 1=正常, 0=删除
deleted_time datetime     -- 删除时间
```

**模式2（Qareport Product）**：
```sql
vd int            -- 1=有效, 0=已删除
delete_time datetime
delete_des varchar(255)  -- 删除原因（可追溯）
```

### 8.4 索引规范

- 外键字段 → 建立 INDEX（如 `report_id`、`equipment_id`、`category_id`）
- 唯一字段 → UNIQUE KEY（如 `equipment_no`）
- 常用查询条件 → INDEX（如 `status`、`next_inspection_date`、`upload_time`）

## 十、Model 代码生成流程

1. 在数据库中创建新表（确保符合命名和字段规范）
2. 配置 `dbconfig/mysql/config.properties` 中的 `model_package`
3. 运行 JBolt 代码生成器（后台管理 → 代码生成）
4. 生成器自动创建 `base/BaseXxxModel.java`
5. 手动创建 `XxxModel.java`（继承 BaseModel + @TableBind 注解）

**注意**：`base/` 目录下的文件每次重新生成会覆盖，因此**不能手动修改**。
