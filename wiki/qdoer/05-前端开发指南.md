## 二、Enjoy 模板引擎核心语法

### 2.1 输出变量

```html
<!-- 输出变量（自动转义） -->
<span>#(userName)</span>
<span>${userName}</span>

<!-- 安全输出（空值时不报错） -->
<span>#(userName??)</span>

<!-- 空值默认值 -->
<span>#(userName ?? '未知')</span>
```

### 2.2 条件判断

```html
<!-- if/else -->
#if(user != null)
    <span>欢迎 #(user.name)</span>
#else
    <span>请登录</span>
#end

<!-- if/else if -->
#if(status == 1)
    <span class="badge badge-success">正常</span>
#else if(status == 0)
    <span class="badge badge-danger">禁用</span>
#else
    <span class="badge badge-secondary">未知</span>
#end

<!-- switch（模板中常用 if-else if 链） -->
#if(data.insp == 1)
    <span class="badge badge-secondary">${data.inspName}</span>
#else if(data.insp == 2)
    <span class="badge badge-info">${data.inspName}</span>
#else if(data.insp == 3)
    <span class="badge badge-warning">${data.inspName}</span>
#else if(data.insp == 4)
    <span class="badge badge-danger">${data.inspName}</span>
#else if(data.insp == 5)
    <span class="badge badge-success">${data.inspName}</span>
#end
```

### 2.3 循环

```html
<!-- for 循环 -->
#for(item : list)
    <tr>
        <td>#(item.name)</td>
        <td>#(item.age)</td>
    </tr>
#end

<!-- for + index -->
#for(item : list)
    <tr>
        <td>#(for.index + 1)</td>
        <td>#(item.name)</td>
    </tr>
#end
```

### 2.4 模板包含

```html
<!-- 引入其他模板文件 -->
#include("/_view/_admin/common/_formjs.html", formId="customerForm")

<!-- 引入公共头部 -->
#include("/_view/_admin/common/_header.html")
```

### 2.5 模板函数

```html
<!-- 定义函数块 -->
#define js()
<script>
    // 页面 JS 代码
</script>
#end
```

### 2.6 共享对象访问

```html
<!-- ProjectConfig 中注入的共享对象，模板中可直接访问 -->
#if(JBoltUserKit.getUserId() != null)
    <span>已登录</span>
#end

<!-- CACHE 对象 -->
#set(value = CACHE.someMethod())
```

### 2.7 行号函数

```html
<!-- rownum：根据 pageNumber/pageSize/index 自动计算行号 -->
${pageNumber, pageSize, index | rownum}
<!-- 结果：第1页，每页10条，第0条 → 显示 1 -->
```

### 2.8 变量赋值

```html
<!-- set 指令 -->
#set(pageId = RandomUtil.random(6))
#set(isAdmin = true)
```

## 三、JBolt 页面布局体系

### 3.1 基础结构

```html
#@jboltLayout()              <!-- 继承 JBolt 主布局 -->
#define main()                <!-- 主内容区域 -->
#set(pageId=RandomUtil.random(6))  <!-- 生成唯一页面ID -->

<div class="jbolt_page" data-key="#(pmkey)">
    <!-- 页面标题/工具栏 -->
    <div class="jbolt_page_title">
        <div class="row">
            <!-- 搜索框 -->
            <div class="col">
                <form class="form-inline" id="xxxForm_#(pageId)"
                      onsubmit="return false;" method="post">
                    <input type="text" class="form-control" 
                           placeholder="输入关键字搜索" name="keywords"/>
                    <button type="submit" class="btn btn-outline-secondary">
                        <i class="fa fa-search"></i> 查询
                    </button>
                </form>
            </div>
            <!-- 操作按钮 -->
            <div class="col-md-auto">
                <button data-dialogbtn data-area="350,250"
                    data-handler="refreshJBoltTable" data-title="新增"
                    data-url="admin/siargo/customer/add"
                    class="btn btn-outline-primary btn-sm">
                    <i class="fa fa-plus"></i> 新增
                </button>
            </div>
        </div>
    </div>
    
    <!-- 页面内容区域 -->
    <div class="jbolt_page_content">
        <!-- JBoltTable 数据表格 -->
        ...
    </div>
</div>
#end
```

### 3.2 布局组件

| CSS 类 | 用途 | 说明 |
|--------|------|------|
| `jb_vflex` | 垂直弹性布局容器 | 占满高度，内容自适应 |
| `jb_vbody` | 可滚动内容区 | 内容溢出时滚动 |
| `fill_box` | 填充容器 | 自动填充剩余空间 |
| `jbolt_page` | 页面容器 | 标准页面根元素 |
| `jbolt_page_title` | 标题栏 | 放置搜索和操作按钮 |
| `jbolt_page_content` | 内容区域 | 放置表格等主要内容 |
| `jbolt_page_tabs` | Tab 页容器 | 多标签页切换 |

## 四、JBoltTable 完整使用手册

### 4.1 基本结构

```html
<!-- ====== 数据行模板（放在 textarea 中） ====== -->
<textarea class="jb_tpl_box" id="customerRowtpl_#(pageId)">
{@each datas as data,index}
<tr data-id="${data.id}">
    <td>${pageNumber,pageSize,index | rownum}</td>
    <td>${data.name}</td>
    <td>
        <a href="admin/siargo/customer/edit/${data.id}" 
           data-area="350,250" tooltip data-title="修改"
           data-handler="refreshJBoltTable"
           class="jbolt_table_editbtn">
           <i class="fa fa-pencil"></i>
        </a>
        <a href="admin/siargo/customer/delete/${data.id}" 
           data-ajaxbtn data-loading="执行中" tooltip 
           data-title="删除" data-handler="refreshJBoltTable"
           data-confirm="确定删除此数据？"
           class="jbolt_table_delbtn c-danger">
           <i class="fa fa-remove"></i>
        </a>
    </td>
</tr>
{@/each}
</textarea>

<!-- ====== 表格定义 ====== -->
<table class="jbolt_table jbolt_main_table table-center"
    data-jbolttable              <!-- 标记为 JBolt 表格 -->
    data-height="fill"           <!-- 高度填充 -->
    data-ajax="true"             <!-- AJAX 加载数据 -->
    data-url="admin/siargo/customer/datas"  <!-- 数据请求 URL -->
    data-column-resize="true"    <!-- 列宽可调整 -->
    data-conditions-form="customerForm_#(pageId)"  <!-- 搜索表单ID -->
    data-rowtpl="customerRowtpl_#(pageId)"         <!-- 行模板ID -->
    data-page="customerPage_#(pageId)"             <!-- 分页组件ID -->
    data-fixed-columns-left="1,2"                  <!-- 左侧固定列 -->
    data-fixed-columns-right="-1">                 <!-- 右侧固定列 -->
    
    <thead class="fw-normal">
        <tr>
            <th data-width="60">序号</th>
            <th data-min-width="150" data-column="name">客户名称</th>
            <th data-width="150">操作</th>
        </tr>
    </thead>
    <tbody></tbody>
</table>
```

### 4.2 核心属性

| 属性 | 说明 | 示例值 |
|------|------|--------|
| `data-jbolttable` | 标记为 JBolt 表格 | - |
| `data-url` | 数据请求 URL | `admin/siargo/customer/datas` |
| `data-ajax` | 使用 AJAX 加载 | `true` |
| `data-height` | 表格高度 | `fill` 填充 / `500` 固定 |
| `data-rowtpl` | 行模板 textarea 的 ID | `customerRowtpl_#(pageId)` |
| `data-page` | 分页组件 ID | `customerPage_#(pageId)` |
| `data-conditions-form` | 搜索表单 ID | `customerForm_#(pageId)` |
| `data-column-resize` | 列宽可拖拽调整 | `true` |
| `data-fixed-columns-left` | 左侧固定列索引 | `1,2` |
| `data-fixed-columns-right` | 右侧固定列索引 | `-1`（最后一列） |
| `data-auto-load` | 自动加载数据 | `true`（默认） |

### 4.3 行模板语法

```html
<!-- each 循环 datas 数组 -->
{@each datas as data,index}
<tr data-id="${data.id}">                    <!-- data-id 标记行ID -->
    <!-- 序号：自动计算 -->
    <td>${pageNumber,pageSize,index | rownum}</td>
    
    <!-- 字段输出 -->
    <td>${data.name}</td>
    <td>${data.createTime}</td>
    
    <!-- 条件渲染的 badge -->
    <td>
        {@if data.status == 1}
            <span class="badge badge-success">正常</span>
        {@else}
            <span class="badge badge-danger">禁用</span>
        {@/if}
    </td>
    
    <!-- Dialog 弹窗链接 -->
    <td>
        <a href="admin/siargo/customer/edit/${data.id}"
           data-dialogbtn data-area="350,250"
           data-title="编辑" data-handler="refreshJBoltTable">
           <i class="fa fa-pencil"></i>
        </a>
    </td>
</tr>
{@/each}
```

### 4.4 操作按钮类型

```html
<!-- Dialog 弹窗按钮 -->
<a data-dialogbtn 
   href="admin/siargo/xxx/edit/${data.id}"
   data-area="350,250"
   data-title="编辑"
   data-handler="refreshJBoltTable">
   编辑
</a>

<!-- AJAX 请求按钮（删除等危险操作） -->
<a data-ajaxbtn
   href="admin/siargo/xxx/delete/${data.id}"
   data-confirm="确定删除？"
   data-handler="refreshJBoltTable"
   class="jbolt_table_delbtn c-danger">
   删除
</a>

<!-- 普通链接 -->
<a href="admin/siargo/xxx/details?id=${data.id}"
   data-dialogbtn data-area="675,860">
   查看详情
</a>
```

### 4.5 data-handler 回调值

| 值 | 说明 |
|----|------|
| `refreshJBoltTable` | 刷新当前表格 |
| `closeDialog` | 关闭弹窗 |
| `closeAndRefresh` | 关闭弹窗并刷新 |

## 六、表单组件

### 6.1 _form.html 模板模式

**_form.html** 是共用的表单模板，被 add.html 和 edit.html 包含：

```html
<!-- add.html -->
#@jboltLayout()
#define main()
<!-- 引入表单模板 -->
#include("_form.html", action="admin/siargo/customer/save")
#end

<!-- edit.html -->
#@jboltLayout()
#define main()
<!-- 同一个模板，不同的 action -->
#include("_form.html", action="admin/siargo/customer/update")
#end
```

### 6.2 完整表单结构

```html
<!-- _form.html -->
<form onsubmit="return false;" id="customerForm" action="#(action)" method="post">
    <!-- 隐藏字段：ID -->
    <input type="hidden" name="customer.id" value="#(customer.id??)" />
    
    <div class="row">
        <div class="col">
            <div class="form-group row">
                <label class="col-sm-3 col-form-label">客户名称</label>
                <div class="col">
                    <input type="text" 
                           data-rule="required"              <!-- 必填校验 -->
                           data-with-clearbtn="true"         <!-- 清空按钮 -->
                           autocomplete="off"
                           class="form-control"
                           placeholder="请输入客户名称"
                           maxlength="50"
                           name="customer.name"              <!-- ★ 命名规范 -->
                           value="#(customer.name??)"/>      <!-- ★ 安全输出 -->
                </div>
            </div>
        </div>
    </div>
</form>

<!-- ★ 引入表单JS处理 -->
#define js()
<script>
</script>
#include("/_view/_admin/common/_formjs.html", formId="customerForm")
#end
```

### 6.3 表单命名规范

**核心规则**：表单字段名必须遵循 `Model前缀.字段名` 格式，对应后端的 `getModel(Xxx.class, "前缀")`。

```html
<!-- 后端: getModel(Customer.class, "customer") -->
<input name="customer.name" value="#(customer.name??)"/>
<input type="hidden" name="customer.id" value="#(customer.id??)"/>

<!-- 后端: getModel(Qareport.class, "qareport") -->
<input name="qareport.order_id" value="#(qapro.orderId??)"/>
<input name="qareport.cust_id" value="#(qapro.custId??)"/>
```

### 6.4 表单校验

```html
<!-- HTML5 校验属性 -->
<input data-rule="required" />           <!-- 必填 -->
<input data-rule="email" />              <!-- 邮箱 -->
<input data-rule="digits" />             <!-- 数字 -->
<input type="number" min="0" max="100"/> <!-- 数字范围 -->

<!-- 带清空按钮 -->
<input data-with-clearbtn="true" />
```

## 七、权限控制在前端

### 7.1 按钮显隐

使用 Enjoy 条件指令，根据 Controller 传递的权限变量控制按钮显隐：

```html
<!-- Controller 传递 -->
#set("accuracy", true)

#if(accuracy)

    </button>
#end

#if(appearance)
    <button class="btn btn-warning" onclick="batchInspection(3)">
        外观检验通过
    </button>
#end
```

### 7.2 条件渲染

```html
<!-- 使用 JBoltUserKit 判断登录状态 -->
#if(JBoltUserKit.getUserId() != null)
    <!-- 已登录内容 -->

<!-- 空值安全判断 -->
#if(data.des != null && data.des != "")
```

## 八、AJAX 交互

### 8.1 声明式 AJAX

```html
<!-- data-ajaxbtn：自动发送 AJAX 请求 -->
<a data-ajaxbtn 
   href="admin/siargo/customer/delete/${id}"
   data-confirm="确定删除？"
   data-handler="refreshJBoltTable">
    删除
</a>
```

### 8.2 手动 AJAX

```javascript
// JBolt 封装的 AJAX 方法（具体方法名依赖 jbolt-admin.js）
// 批量操作示例
function batchAudit(ids) {
    $.post('admin/siargo/equipment/batchAudit', {ids: ids}, function(result) {
        if (result.success) {
            refreshJBoltTable();
        }
    });
}
```

### 8.3 表格自动 AJAX

表格通过 `data-ajax="true"` 和 `data-url="..."` 自动加载数据，无需手动编写请求代码。

## 十一、JBolt Layout 共享模板

### 11.1 布局模板体系

ProjectConfig 中注册的 Layout 模板：

```java
// 后台主布局（pjax 加载）
me.addSharedFunction("/_view/_admin/common/__admin_layout.html");

// Dialog 弹窗布局
me.addSharedFunction("/_view/_admin/common/__admin_dialog_layout.html");

// Iframe 内嵌布局
me.addSharedFunction("/_view/_admin/common/__admin_iframe_layout.html");

// 独立单页布局
me.addSharedFunction("/_view/_admin/common/__admin_singlepage_layout.html");

// JBoltLayer 弹窗布局
me.addSharedFunction("/_view/_admin/common/__admin_jboltlayer_layout.html");

// 自动识别布局（根据请求类型自动选择）
me.addSharedFunction("/_view/_admin/common/__jbolt_layout.html");
```
