## 一、配置文件架构

```
src/main/resources/
├── application.properties      # 主配置（系统名称、环境切换）
├── config.properties           # 开发环境完整配置（60+项）
├── config-pro.properties       # 生产环境配置
├── dbconfig/mysql/
│   └── config.properties       # 数据库连接（加密）
├── caffeine/                   # Caffeine 缓存配置
│   ├── caffeine.properties
│   └── ...
├── redis/                      # Redis 配置（备用）
├── undertow.properties         # Undertow 服务器配置
├── sentinel.properties         # Sentinel 限流配置
├── log4j2.xml                  # 日志框架配置
├── logging.properties          # JDK日志（备用）
├── ehcache.xml                 # Ehcache 配置（备用）
├── applicationContext.xml      # Spring 上下文（ureport 需要）
├── permission_init.json        # 权限初始化数据
├── dictionary_init.json        # 字典初始化数据
└── extend_dictionary_init.json # 扩展字典初始化
```

```
application.properties
  └── pdev = dev ──→ 加载 config.properties
  └── pdev = pro ──→ 加载 config-pro.properties
```

## 五、缓存策略详解

### 5.1 Caffeine 缓存（默认）

```properties
jbolt_cache_type = caffeine
jbolt_cache_name = jbolt_cache
```

### 5.2 业务缓存模式代码模板

```java
// ====== 缓存字段 ======
private static final long CACHE_TTL = 10 * 60 * 1000L;  // TTL 毫秒
private volatile Map<String, Long> cachedData;
private volatile long cacheTimestamp;
private final ReentrantLock cacheLock = new ReentrantLock();

// ====== 获取缓存 ======
public Map<String, Long> getCachedData() {
    // 第一重检查：无锁快速路径
    if (cachedData != null && 
        (System.currentTimeMillis() - cacheTimestamp) < CACHE_TTL) {
        return cachedData;
    }
    // 加锁
    cacheLock.lock();
    try {
        // 第二重检查：防止并发穿透
        if (cachedData != null && 
            (System.currentTimeMillis() - cacheTimestamp) < CACHE_TTL) {
            return cachedData;
        }
        // 从数据库加载
        Map<String, Long> fresh = loadFromDb();
        cachedData = fresh;
        cacheTimestamp = System.currentTimeMillis();
        return fresh;
    } finally {
        cacheLock.unlock();
    }
}

// ====== 清除缓存 ======
public void clearCache() {
    cachedData = null;
    cacheTimestamp = 0;
}
```

### 5.3 缓存刷新时机

以下操作后必须调用 `clearCache()`：
- `save()` 新增数据
- `update()` 更新数据
- `delete()` 删除数据
- `batchInspection()` 批量审批
- `batchStatus()` 批量状态变更

## 十、开发环境切换操作

1. 修改 `application.properties`：
   ```properties
   pdev = dev    # 开发环境 → 加载 config.properties
   pdev = pro    # 生产环境 → 加载 config-pro.properties
   ```

2. 开发环境（dev）特点：
   - `dev_mode = true`：显示更多调试信息
   - `jbolt_druid_dev_mode_full_sql_log = true`：输出完整 SQL
   - `wechat_dev_mode = true`：微信开发模式

3. 生产环境（pro）特点：
   - 使用 `config-pro.properties` 中的加密数据库连接
   - 关闭开发模式调试日志
